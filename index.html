Key Architecture Decisions
Server-Side Spoofing
Data corruption happens inside UE5's authoritative server before replication. No external packet interception — impossible with UE5's proprietary bit-packing.
LiveKit SFU for VoIP
WebRTC sessions stay healthy. Audio degradation (static, bitcrushing, gating) applied client-side via Web Audio API based on SINR values.
Dual World State
Server maintains Ground Truth + per-player Degraded View. Both logged at 10Hz for AAR Reality Delta analysis.
RF Physics Engine
FSPL + Fresnel zone raycasting over ISRO CartoDEM / SRTM terrain. Computes per-player SINR every server tick.

Feasibility & Viability

Feasibility Analysis

✅ Technical Feasibility
RF Math: Verified
FSPL, Fresnel zones, link budgets — all equations verified against ITU-R P.525 & P.530 standards
Web Audio DSP: Proven
Client-side audio degradation via standard browser APIs — no plugins, no latency overhead
UE5 Server Authority: Native
Server-side replication is UE5's core design pattern — we work with the engine, not against it
Indian DEM Available
ISRO CartoDEM (30m) covers India nationally. SRTM provides global fallback. Both free.
⚠ Challenges & Risks
Defense Procurement Cycle
DAP 2020 process (AoN → RFP → Trials → Contract) can take 2-4 years end-to-end
Server Tick Budget
RF link budget for every player pair every tick — O(n²) scaling needs optimization
Classified Terrain Data
High-res DEM for LAC/LoC border areas may require NRSC/MoD clearance beyond 30m resolution
AI Bias Calibration
LLM companion must give plausibly wrong advice, not obviously wrong — careful prompt engineering needed
🛡 Mitigation Strategies
DAP Make-II / iDEX Route
Industry-funded prototype (Make-II) with guaranteed procurement order on success. iDEX grants for initial R&D.
Spatial Partitioning
Only compute RF for players within max radio range — grid-based culling reduces to O(n)
Start with Synthetic Terrain
Use freely available 30m DEM for generic scenarios first. Seek NRSC clearance for border-specific maps separately.
Prompt Engineering + Guardrails
LLM receives degraded sensor data via prompt — produces naturally wrong output without custom model training
