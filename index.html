Key Architecture Decisions
Server-Side Spoofing
Data corruption happens inside UE5's authoritative server before replication. No external packet interception — impossible with UE5's proprietary bit-packing.
LiveKit SFU for VoIP
WebRTC sessions stay healthy. Audio degradation (static, bitcrushing, gating) applied client-side via Web Audio API based on SINR values.
Dual World State
Server maintains Ground Truth + per-player Degraded View. Both logged to InfluxDB at 10Hz for AAR Reality Delta analysis.
RF Physics Engine
FSPL + Fresnel zone raycasting over DEM terrain. Computes per-player SINR every server tick to drive voice and data degradation.
Unreal Engine 5 LiveKit SFU Redis Pub/Sub InfluxDB Web Audio API PostgreSQL React + Node.js Python FastAPI

Feasibility & Viability

Feasibility Analysis

✅ Technical Feasibility
RF Math: Verified
FSPL, Fresnel zones, link budgets — all equations verified against ITU-R P.525 & P.530 standards
Web Audio DSP: Proven
Client-side audio degradation via standard browser APIs — no plugins, no latency overhead
UE5 Server Authority: Native
Server-side replication is UE5's core design pattern — we work with the engine, not against it
All Components: COTS
Every technology (UE5, LiveKit, Redis, InfluxDB) is production-proven and open-source or free-tier
⚠ Challenges & Risks
DEM Terrain Data
Real LOS raycasting requires high-resolution Digital Elevation Model data (SRTM / GeoTIFF)
Server Tick Budget
RF link budget for every player pair every tick — O(n²) scaling needs optimization
Military Accreditation
Defense procurement requires security clearances, ITAR compliance, IL4+ hosting
AI Bias Calibration
LLM companion must be carefully tuned to give plausibly wrong advice, not obviously wrong
🛡 Mitigation Strategies
Use NASA SRTM (Free)
30m resolution, global coverage, freely available — sufficient for training scenarios
Spatial Partitioning
Only compute RF for players within max radio range — grid-based culling reduces to O(n)
Start with NATO Partners
Target allied nations with simpler procurement first (UK DSTL, AUS DST Group)
Prompt Engineering + Guardrails
LLM receives degraded data via prompt — produces naturally wrong output without custom training
